# Guide de contribution

Merci de vouloir contribuer à ce projet ! Voici comment participer efficacement :

## Proposer une amélioration ou signaler un bug
- Ouvre une issue GitHub avec un maximum de détails (étapes, logs, contexte).
- Pour une nouvelle fonctionnalité, explique le besoin et l'usage attendu.

## Soumettre une Pull Request
- Forke le dépôt, crée une branche dédiée (`feature/ma-fonctionnalite` ou `fix/mon-bug`).
- Respecte le style de code (TypeScript, Prettier, ESLint).
- Ajoute des tests si possible.
- Décris clairement ta PR (ce qu'elle change, pourquoi).

## Bonnes pratiques
- Un commit = une idée claire.
- Privilégie des messages de commit explicites.
- Sois respectueux dans les échanges (voir Code de Conduite).

## Stack technique
- Next.js 15, TypeScript, Prisma, PostgreSQL, TailwindCSS
